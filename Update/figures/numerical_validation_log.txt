Experiment 4: CN- Null Test - Noise Floor for A
======================================================================
Question: Is A(CN-) = 0.08 nats plausibly a noise floor,
or does it indicate a deeper problem?

Noise model               Mean A       Max A        P(A > 0.08)    
-----------------------------------------------------------------
Gaussian (1e-3)           0.000018     0.000098     0.0000         
Gaussian (1e-2)           0.001243     0.006404     0.0000

Gaussian (0.1)            0.061744     0.232245     0.2662         
Orthogonal noise (1%)     0.002301     0.017726     0.0000         
Orthogonal noise (5%)     0.035606     0.196862     0.0815         

Analysis:
  The manuscript reports A(CN-) = 0.08 nats.
  The analytical model predicts A(CN-) ~ 1e-3 to 1e-4 nats.
  Reproducing 0.08 from noise requires projection noise levels
  of 5-10%, far exceeding typical DIRAC precision (< 1e-6).
  Conclusion: A(CN-) = 0.08 is NOT plausibly a noise floor.

======================================================================
 SUMMARY OF FINDINGS
======================================================================

1. PAIRING ALGORITHM: Optimal (Hungarian) pairing is robust against
   small perturbations. Energy ordering can differ significantly when
   orbitals are nearly degenerate. Always use optimal pairing for eta.

2. SPURIOUS SIGMA CHARACTER: Projection noise at the 1-2% level creates
   only small spurious sigma character in the |omega|=3/2 orbital. The
   reported 3.8% cannot be explained by typical numerical noise.

3. SUBSPACE CLOSURE: A 3x3 sub-block of a unitary matrix is unitary only
   if the subspace is closed (no leakage to virtual orbitals). If the
   bonding subspace mixes with lone pairs or sigma* orbitals, the 3x3
   block will not be unitary.

4. CN- NOISE FLOOR: A(CN-) = 0.08 nats is not a plausible noise floor.
   It requires 5-10% projection noise, far exceeding typical DIRAC
   precision. This indicates systematic rather than random errors.

5. BASIS SET INCOMPLETENESS: At triple-zeta quality, basis set noise
   should be < 0.01%. The reported 3.8% sigma contamination is too large
   to be from basis set incompleteness alone.
